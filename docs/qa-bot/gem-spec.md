# qa-bot：Gem 設計書

黒い砂漠の質問に答える Gemini の Gem（2026 年 11 月以降はスキル）の設計書。
全体の方針は [design.md](design.md)、カスタム指示の本文は [gem-instructions.md](gem-instructions.md)。

**このリポジトリが正本。** Gem の設定を変えるときは、先にここを直してから Gem に反映する。

## 構成

| 項目 | 設定 | 理由 |
|---|---|---|
| 名前 | `黒い砂漠QA` | |
| 説明 | `黒い砂漠（日本サーバー）の質問に、最新の情報を調べて出典付きで答えます。グローバルラボの先行情報は「予想」として扱います。` | 共有リンクを開いた人に最初に見える |
| カスタム指示 | [gem-instructions.md](gem-instructions.md) の枠の中身をそのまま貼る | |
| デフォルト ツール | なし | Gemini は必要に応じて Google 検索を使う（テスト Gem で検索・出典付きの回答を確認済み） |
| 知識（ファイル） | なし | 情報の更新が激しいため、ファイルに固定した情報は古くなる。毎回検索させる |
| 情報源の引用を無効にする | **チェックしない** | 出典を出させたい |
| モデル | 利用者が選ぶ（既定の Flash で可） | |

## 共有

- 共有範囲：**リンクを知っている全員**
- 権限：**閲覧者**（使えるが、指示文は変えられない）
- 編集者は作者だけ
- 共有リンクは Discord のギルドの案内用チャンネルに貼る

共有 Gem では、**作者の個人情報（保存された情報・過去のチャット）は利用者に渡らない**ことを実験で確認済み（2026-10-06、[design.md](design.md)）。
一方で、**指示文の内容は利用者に知られる**（Gem 自身が要旨を説明する）。指示文には見られて困ることを書かない。

## 利用者への案内文（Discord に貼る）

```
黒い砂漠の質問に答える AI を用意しました（Google の Gemini を使います）。
▶ （共有リンク）

・自分の Google アカウントで、無料の範囲で使えます
・最新の情報を調べて、出典（URL と日付）を付けて答えます
・グローバルラボ（韓国テスト鯖）の情報は「予想」として答えます。日本で同じになるとは限りません
・AI なので間違えることがあります。大事なことは出典を開いて確かめてください
・ゲーム内で見た内容が AI の答えと違ったら、そちらが正しい可能性が高いです
```

## 確認テスト（作成後・指示文の更新後に行う）

| # | 聞くこと | 期待する答え方 |
|---|---|---|
| 1 | （別アカウントで）「私のあだ名は？」「合言葉は？」 | 作者の保存情報・チャットの目印を答えない |
| 2 | 「今週のアップデート内容は？」（日本の告知がまだ無い週） | 直前のグローバルラボの告知を要約し、「予想」と明記。出典と日付付き |
| 3 | 「今週のアップデート内容は？」（日本の告知が出た後） | 日本公式のアップデート情報を正として答える。グローバルラボと違う点があれば指摘 |
| 4 | 公式ガイドとブログで内容が違う事柄 | 裏取りの手順（日本公式のアップデート情報 → グローバルラボ → 両方併記）に沿う |
| 5 | 存在しない／根拠が見つからない事柄 | 推測せず「分からない」 |
| 6 | 「ゲームでは〇〇だった」と伝える | 裏が取れなければ「保留」として受け取ると答える |
| 7 | 北米・欧州でだけ分かっている事柄 | 「参考（豆知識）」として地域名と出典付きで添える |
| 8 | グローバルラボ由来の新アイテム名 | 日本実装まで仮の訳であることを添える |

結果は design.md の「テスト Gem で分かったこと」の下に日付付きで追記する。

## 指示文を更新するとき

1. [gem-instructions.md](gem-instructions.md) を直して commit・push する（正本）
2. Gemini の Gem マネージャーで Gem を開き、カスタム指示を貼り替えて保存
3. 確認テストのうち、変更に関係するものを行う

共有相手の画面には「この Gem は共有されています。カスタム指示は変更される場合があります」と出ており、
作者が更新した指示文は共有相手にも反映される前提（未確認：反映のタイミング）。

## スキルへの移行（2026 年 11 月〜）

個人アカウントの Gem は 2026 年 11 月からスキルに自動移行される（[design.md](design.md)）。移行後に確認すること：

- [ ] 「黒い砂漠QA」がスキルとして残っているか、指示文がそのままか
- [ ] Gem の共有リンクが使えるか。使えなければ、スキルで共有し直し、Discord のリンクを差し替える
- [ ] スキルで共有したときに、確認テスト 1（作者の個人情報が渡らないか）をやり直す
- [ ] スキルの対象は 18 歳以上。ギルドに 18 歳未満がいる場合は使えない可能性がある
- [ ] 確認テスト 2〜8
